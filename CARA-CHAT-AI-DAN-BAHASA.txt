CATATAN FITUR AI DAN BAHASA

Versi bersih ini menonaktifkan koneksi AI langsung dari browser karena kunci API tidak boleh disimpan di file JavaScript publik.
Jika fitur AI ingin diaktifkan kembali, gunakan endpoint server-side dengan environment variable untuk menyimpan kunci API.
Jangan menaruh API key rahasia, token akses, OTP, atau kredensial pengguna di HTML/JavaScript publik.
