CARA UPLOAD VERSI BERSIH

1. Hapus seluruh isi website lama di public_html terlebih dahulu agar file lama tidak tertinggal.
2. Upload seluruh isi folder mujahiid-main dari paket ini ke public_html.
3. Pastikan file .htaccess ikut terupload.
4. Pastikan folder blk, metode, alat-digital-marketing, dan data ikut terupload.
5. Jangan mengunggah kembali folder atau file dari versi lama yang sudah dihapus.
6. Setelah upload, buka beranda domain dan /blk/ untuk memastikan halaman tampil normal.
7. Balas tiket penyedia hosting dan minta pemeriksaan ulang setelah konten lama benar-benar terhapus.
