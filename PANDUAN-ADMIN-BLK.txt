PANDUAN AKTIVASI ADMIN PORTAL PELATIHAN BLK

1. Buka Firebase Console untuk project: akses-canva-pro-terbatas.

2. Aktifkan login admin:
   - Buka Authentication.
   - Pilih Sign-in method.
   - Aktifkan Email/Password.
   - Buka tab Users, lalu pilih Add user.
   - Masukkan email dan password khusus admin.

3. Pasang Firestore Rules:
   - Buka Firestore Database > Rules.
   - Salin isi file firestore-rules-blk.rules.
   - Gabungkan dengan rules lama jika rules lama masih dipakai halaman lain.
   - Klik Publish.

4. Pasang Storage Rules:
   - Buka Storage > Rules.
   - Salin isi file storage-rules-blk.rules.
   - Gabungkan dengan rules lama jika rules lama masih dipakai.
   - Klik Publish.

5. Upload seluruh folder situs ke hosting.

6. Buka halaman admin:
   https://domain-anda.com/admin-blk/

7. Login memakai akun admin yang dibuat di Firebase Authentication.
   Saat login pertama, sistem otomatis menyiapkan data awal materi dan catatan.

FITUR ADMIN
- Menambah file dari perangkat, maksimal 25 MB.
- Menambah link eksternal.
- Mengedit judul, kategori, deskripsi, format, dan urutan materi.
- Menampilkan atau menyembunyikan materi.
- Menghapus materi dan file unggahan.
- Menulis, mengedit, menyematkan, menyembunyikan, dan menghapus catatan.
- Membuka atau menutup akses portal peserta.
- Memasang atau menghapus password peserta.
- Mengubah judul, deskripsi, sambutan, dan link bantuan WhatsApp.

CATATAN KEAMANAN
- Jangan menyimpan password admin di file HTML atau JavaScript.
- Gunakan password admin yang kuat dan berbeda dari password peserta.
- Password peserta disimpan sebagai hash SHA-256, bukan teks asli.
- Link file bawaan lama masih dapat dibuka jika seseorang mengetahui alamat file langsung.
  Gunakan unggahan Firebase Storage untuk file baru yang dikelola dari halaman admin.
