============================================================
PANDUAN ADMIN PORTAL BLK - VERSI SUPABASE STORAGE
============================================================

VERSI INI TIDAK MENGGUNAKAN FIREBASE STORAGE.

Arsitektur:
- Firebase Authentication : login admin utama
- Firestore               : data modul, catatan, URL/path, pengaturan portal
- Supabase Auth           : otorisasi upload/hapus Storage
- Supabase Storage        : contoh foto + file materi dari perangkat
- Vercel                  : hosting website

Untuk pemasangan pertama, ikuti langkah lengkap di:
PANDUAN-SUPABASE-BLK.txt

File setup Supabase:
SUPABASE-SETUP.sql

File konfigurasi yang harus diisi:
admin-blk/supabase-config.js

============================================================
FITUR MATERI LENGKAP
============================================================

Setiap modul mempunyai tiga bagian:
1. FILE MATERI
2. CATATAN
3. CONTOH FOTO

Admin dapat mengatur masing-masing bagian agar tampil atau disembunyikan.
Menyembunyikan bagian tidak menghapus isinya.

CONTOH FOTO
- Admin dapat menambah beberapa foto.
- Admin dapat memberi judul dan keterangan.
- JPG, PNG, WEBP.
- Maksimal 8 MB per foto.
- Disimpan di Supabase Storage.
- Peserta hanya melihat pratinjau.
- Tidak ada tombol edit atau download untuk peserta.

FILE MATERI
- Mode Upload dari perangkat memakai Supabase Storage.
- Maksimal 25 MB per file.
- Mode Link tetap bisa dipakai untuk file yang sudah berada di Google Drive,
  website lain, dan sebagainya.

CATATAN
- Tetap disimpan di Firestore.
- Tidak memerlukan Supabase Storage.

============================================================
UPLOAD KE GITHUB
============================================================

Untuk versi update ini, unggah/ganti:
1. admin-blk/index.html
2. admin-blk/supabase-config.js
3. blk/index.html

Setelah setup Supabase selesai, file berikut tidak wajib dipasang di website:
- SUPABASE-SETUP.sql
- PANDUAN-SUPABASE-BLK.txt
- PANDUAN-ADMIN-BLK.txt

============================================================
PENTING
============================================================

Jangan menaruh Supabase Secret key atau service_role key di HTML/JavaScript.
Gunakan Publishable key atau anon/public key saja.

Setelah pertama kali memasang Supabase, Logout dari halaman admin lalu Login
ulang agar sesi Firebase dan Supabase aktif bersama.
