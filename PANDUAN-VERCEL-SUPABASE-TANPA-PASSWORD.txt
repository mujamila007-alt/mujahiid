BLK - SUPABASE TANPA PASSWORD SUPABASE
=======================================

1. Admin tetap login memakai FIREBASE EMAIL + PASSWORD.
2. Supabase Authentication TIDAK dipakai.
3. Untuk upload foto, Vercel API memakai Supabase Secret Key di server.

YANG WAJIB DI VERCEL
--------------------
Buka Vercel > Project > Settings > Environment Variables.
Tambah satu variable:

Name : SUPABASE_SECRET_KEY
Value: sb_secret_...

Ambil Value dari Supabase > Settings > API Keys > Secret keys.
Jangan masukkan secret key ke GitHub, HTML, atau supabase-config.js.

Setelah Save, lakukan Redeploy.

LOGIN BERMASALAH?
-----------------
Pada /admin-blk/, isi email Firebase lalu klik:
"Lupa password Firebase? Kirim email reset"

Buka email reset Firebase, buat password baru, lalu login kembali.
Supabase tidak terlibat dalam proses login.
