BLK - SUPABASE STORAGE TANPA PASSWORD SUPABASE
================================================

VERSI INI TIDAK MEMAKAI LOGIN SUPABASE AUTH.
Admin cukup login seperti biasa memakai Firebase Authentication.
Supabase hanya digunakan untuk menyimpan file/foto.

FILE YANG DIUPLOAD KE GITHUB
----------------------------
1. Ganti: admin-blk/index.html
2. Tambah folder root: api/
   - api/supabase-storage.js
3. Tambah di root: package.json
4. JANGAN ganti admin-blk/supabase-config.js milik Anda yang sudah berisi Project URL + Publishable Key.

ENVIRONMENT VARIABLES DI VERCEL
-------------------------------
Buka Vercel > project Anda > Settings > Environment Variables.
Tambahkan:

SUPABASE_URL
= Project URL Supabase Anda, contoh https://xxxx.supabase.co

SUPABASE_SECRET_KEY
= Secret key Supabase yang diawali sb_secret_...
  Ambil dari Supabase > Settings > API Keys > Secret keys.
  KEY INI HANYA BOLEH DISIMPAN DI VERCEL ENVIRONMENT VARIABLES.
  JANGAN dimasukkan ke HTML, GitHub, atau supabase-config.js.

SUPABASE_BUCKET
= blk-assets

ADMIN_EMAILS
= email akun Firebase admin yang boleh upload.
  Jika lebih dari satu, pisahkan dengan koma.
  Contoh: admin1@email.com,admin2@email.com

Pilih Environment: Production, Preview, Development bila tersedia.
Kemudian SAVE dan lakukan REDEPLOY.

CARA KERJA
----------
1. Admin login dengan Firebase seperti sebelumnya.
2. Browser meminta Firebase ID Token.
3. /api/supabase-storage memverifikasi token Firebase.
4. Vercel membuat signed upload token menggunakan Supabase Secret Key di server.
5. Browser mengupload file langsung ke Supabase Storage.
6. Password Supabase tidak pernah diminta.

PENTING
-------
- Akun di Supabase Authentication tidak diperlukan untuk upload versi ini.
- User Supabase yang sudah terlanjur dibuat boleh dibiarkan atau dihapus.
- Publishable Key tetap di admin-blk/supabase-config.js.
- Secret Key hanya di Vercel Environment Variables.
- Bucket blk-assets yang sudah Anda buat tetap dipakai.

SETELAH DEPLOY
--------------
1. Logout admin.
2. Login lagi dengan email/password Firebase yang biasa.
3. Buka salah satu Materi > Kelola File & Catatan > Contoh Foto.
4. Upload satu JPG/PNG kecil untuk tes.

OPSIONAL SETELAH SEMUA BERHASIL
-------------------------------
Jalankan SUPABASE-RLS-CLEANUP-OPSIONAL.sql di SQL Editor Supabase.
Ini menghapus policy upload/hapus lama berbasis Supabase Auth karena sudah tidak diperlukan.
