==============================

PENYEBAB
- sb_secret_... dan sb_publishable_... adalah API key Supabase baru dan BUKAN JWT.
- Kode lama mengirim key tersebut sebagai Authorization: Bearer sehingga dibaca sebagai JWT.

YANG SUDAH DIPERBAIKI
1. api/supabase-storage.js memakai REST Storage dengan header apikey untuk secret key.
2. admin-blk/index.html mengunggah ke signed URL tanpa Authorization Bearer Supabase.
3. Login admin tetap Firebase.
4. Environment Variables Vercel yang sudah dibuat TIDAK perlu diganti.

UPLOAD / REPLACE KE ROOT GITHUB
- api/supabase-storage.js
- admin-blk/index.html
- package.json

admin-blk/supabase-config.js ikut disertakan sebagai cadangan. Kalau file Anda sudah benar, tidak wajib diganti.

SETELAH COMMIT
