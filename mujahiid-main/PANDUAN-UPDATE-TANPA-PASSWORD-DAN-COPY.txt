UPDATE ADMIN BLK TANPA PASSWORD + COPY TEXT CATATAN
===================================================

PERUBAHAN:
1. Login Admin BLK tidak lagi menampilkan kolom password.
2. Login memakai Firebase Email Link (passwordless).
3. Admin cukup memasukkan email lalu klik "Kirim Link Masuk".
4. Buka email dan klik link dari Firebase. Admin langsung masuk.
5. Upload file/foto Supabase tetap memakai sesi Firebase yang sama.
6. Setiap Catatan Pelatihan sekarang memiliki tombol "Copy Text".

FILE YANG PERLU DIGANTI DI GITHUB:
- admin-blk/index.html
- blk/index.html

TIDAK PERLU MENGUBAH:
- admin-blk/supabase-config.js
- api/supabase-storage.js
- bucket Supabase blk-assets
- Project URL Supabase
- Publishable Key Supabase

SATU PENGATURAN FIREBASE YANG HARUS DIAKTIFKAN SEKALI SAJA:
1. Buka Firebase Console.
2. Authentication.
3. Sign-in method.
4. Buka Email/Password.
5. Pastikan Email/Password aktif.
6. Aktifkan juga "Email link (passwordless sign-in)".
7. Save.

Jika saat mengirim link muncul pesan bahwa domain belum diizinkan:
Firebase > Authentication > Settings > Authorized domains
Tambahkan domain website/Vercel Anda.

CARA LOGIN SETELAH UPDATE:
1. Buka /admin-blk/
2. Masukkan email admin.
3. Klik "Kirim Link Masuk".
4. Buka email masuk dari Firebase.
5. Klik link.
6. Admin terbuka tanpa memasukkan password.

CARA COPY CATATAN:
1. Peserta buka salah satu Materi Lengkap.
2. Pilih tab Catatan Pelatihan.
3. Klik "Copy Text" pada catatan yang diinginkan.
4. Tombol akan berubah menjadi "Tersalin".

CATATAN:
Login tanpa password tetap menggunakan Firebase Authentication. Ini sengaja dipertahankan agar hak tulis Firestore dan izin upload foto Supabase tetap bekerja tanpa membuka akses admin untuk semua pengunjung.
