PANDUAN PEMBARUAN PORTAL PELATIHAN DIGITAL MARKETING BLK

FILE YANG PERLU DIPERBARUI DI GITHUB
1. Ganti file blk/index.html.
2. Ganti file admin-blk/index.html.
3. Simpan firestore-rules-blk.rules dan storage-rules-blk.rules sebagai panduan rules Firebase.
4. Jangan hapus file atau folder lain di GitHub.
5. Commit perubahan. Vercel akan melakukan deployment otomatis seperti biasanya.

STRUKTUR MATERI BARU
- Satu kartu mewakili satu modul pelatihan.
- Satu modul dapat berisi banyak file dan banyak catatan.
- Contoh: kartu Blogger & Website berisi seluruh template Blogger.
- Contoh: kartu Meta Ads berisi file Pixel, template iklan, copywriting, dan catatan Meta Ads.
- File tidak lagi ditampilkan sebagai kartu terpisah di halaman peserta.
- Peserta membuka kartu modul, lalu memilih tab File Materi atau Catatan Pelatihan.

AKTIVASI FIREBASE
1. Buka Firebase Console untuk project: akses-canva-pro-terbatas.

2. Aktifkan login admin:
   - Buka Authentication.
   - Pilih Sign-in method.
   - Aktifkan Email/Password.
   - Buka tab Users, lalu pilih Add user.
   - Masukkan email dan password khusus admin.

3. Pasang Firestore Rules:
   - Buka Firestore Database > Rules.
   - Salin isi firestore-rules-blk.rules.
   - Gabungkan dengan rules lama jika rules lama juga dipakai halaman lain.
   - Pastikan blok blkModules ikut dipasang.
   - Klik Publish.

4. Pasang Storage Rules:
   - Buka Storage > Rules.
   - Salin isi storage-rules-blk.rules.
   - Gabungkan dengan rules lama jika rules lama juga dipakai.
   - Klik Publish.

ALUR PENGELOLAAN ADMIN
1. Buka https://domain-anda.com/admin-blk/.
2. Login memakai akun admin Firebase Authentication.
3. Login pertama akan membuat modul awal jika koleksi blkModules masih kosong.
4. Pilih menu Modul Pelatihan.
5. Klik Tambah Modul untuk membuat Blogger, Meta Ads, atau materi lainnya.
6. Klik Kelola file & catatan pada kartu modul.
7. Tambahkan beberapa file melalui unggahan atau link eksternal.
8. Tambahkan beberapa catatan pelatihan pada tab Catatan Pelatihan.
9. Gunakan Sembunyikan jika satu modul belum siap untuk peserta.

FITUR ADMIN
- Menambah, mengedit, mengurutkan, menyembunyikan, dan menghapus modul.
- Menyimpan banyak file di dalam satu modul.
- Mengunggah file dari perangkat dengan ukuran maksimal 25 MB.
- Menambahkan link file eksternal.
- Menambah, mengedit, dan menghapus catatan pada setiap modul.
- Membuka atau menutup seluruh akses portal peserta.
- Memasang atau menghapus password peserta.
- Mengubah judul, deskripsi, sambutan, dan link bantuan WhatsApp.

CATATAN DATA LAMA
- Data baru memakai koleksi Firestore bernama blkModules.
- Koleksi lama blkResources dan blkNotes tidak perlu dihapus.
- Rules lama tetap disertakan agar halaman atau data versi sebelumnya tidak terganggu.

CATATAN KEAMANAN
- Jangan menyimpan password admin di file HTML atau JavaScript.
- Gunakan password admin yang kuat dan berbeda dari password peserta.
- Password peserta disimpan sebagai hash SHA-256, bukan teks asli.
- Link file bawaan di folder blk masih dapat dibuka jika seseorang mengetahui alamatnya.
- Gunakan Firebase Storage untuk file baru yang ingin dikelola penuh dari halaman admin.
